# Éléments de communication - Pandora

## Description courte

Pandora est un prototype de tableau de bord de veille qui aide à comprendre plus vite une situation mondiale à partir de signaux publics regroupés dans une interface unique.

## Slogan

**Voir les signaux. Comprendre le contexte. Expliquer avec prudence.**

## Message principal

L'information ouverte est abondante, mais souvent dispersée. Pandora cherche à rendre cette information plus lisible pour aider une équipe à construire une première lecture d'une situation.

## Bénéfices à mettre en avant

- Centralisation de signaux publics.
- Meilleure lisibilité.
- Démonstration pédagogique.
- Gain de temps pour préparer une synthèse.
- Limites clairement assumées.

## Ton recommandé

- Clair.
- Responsable.
- Pédagogique.
- Sobre.
- Non alarmiste.

## À éviter

- Promettre une vérité complète.
- Présenter le projet comme un outil militaire ou de surveillance.
- Utiliser un vocabulaire trop technique.
- Donner l'impression que la décision peut être automatisée.

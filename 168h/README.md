# Rendu 168H - Pandora

Ce dossier contient les livrables du projet Pandora pour le 168H.

Le contenu est volontairement rédigé dans un langage accessible : l'objectif est de cadrer le projet, expliquer sa valeur, préparer la démonstration et réunir les preuves attendues, sans entrer dans les détails techniques du code.

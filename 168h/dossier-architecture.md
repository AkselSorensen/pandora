# Dossier architecture - Pandora 168H

## Vue d'ensemble

Pandora prend la forme d'un tableau de bord web. L'utilisateur accède à une interface unique qui rassemble plusieurs catégories de signaux publics : événements, zones d'intérêt, flux de veille, informations de contexte et indicateurs visuels.

L'objectif de l'architecture n'est pas de montrer une complexité technique, mais de rendre le parcours clair : observer, filtrer, comprendre, expliquer.

## Parcours utilisateur cible

1. L'utilisateur ouvre le tableau de bord.
2. Il choisit une zone ou un thème d'observation.
3. Il active les informations utiles à son analyse.
4. Il repère les signaux importants.
5. Il utilise ces éléments pour raconter une situation.
6. Il garde en tête que les données doivent être interprétées avec prudence.

## Organisation fonctionnelle

- Carte ou vue principale : donner une vision d'ensemble.
- Panneaux d'information : expliquer les signaux observés.
- Couches ou catégories : éviter de tout afficher en même temps.
- Scénario de démonstration : guider le jury dans un cas concret.
- Documentation : expliquer comment lancer, utiliser et limiter le prototype.

## Choix de conception

- Interface visuelle plutôt qu'un rapport statique.
- Regroupement de plusieurs signaux pour éviter la dispersion.
- Démonstration guidée pour rendre le projet compréhensible rapidement.
- Priorité donnée à la lisibilité et à la stabilité pendant la soutenance.

## Contraintes

- Les sources ouvertes peuvent être incomplètes, temporairement indisponibles ou difficiles à interpréter.
- Le prototype ne garantit pas une vision exhaustive d'une situation.
- Les informations affichées doivent rester publiques et non sensibles.
- La démonstration doit fonctionner même si certaines sources ne répondent pas au moment de la soutenance.

## Stratégie de démonstration

La démonstration reposera sur un scénario préparé. Ce scénario montrera comment Pandora peut aider à passer d'une situation dispersée à une lecture plus structurée.

Exemple de scénario :

> Une équipe doit préparer rapidement un point de situation sur une zone internationale. Elle utilise Pandora pour observer différents signaux publics, comparer les informations visibles et produire une synthèse orale prudente.

## Critères de qualité

- L'interface est compréhensible sans formation longue.
- Le scénario est crédible.
- Les limites sont dites clairement.
- Les preuves sont disponibles.
- Le projet peut être lancé ou présenté par un autre membre de l'équipe.
